## 一、V5.0 改版緣起與架構決策（獨立平行版本，絕不動 V4.04）

1. **改版需求（三班導師共議）**：
   - 考量運動會進場表演希望控制在 **2 分鐘以內**，且原曲第 5 段「主歌二」前半與第 1 段前奏重複，因此將音樂與示範影片精簡剪接為：**保留 `0:00–0:16` 前奏，直接接續原片 `1:39–3:13` 至曲末，合成共 `110.0` 秒（`1:50`）兩分鐘精華表演版**。
2. **與 V4.04 完整版完全隔離共存**：
   - 原有 V4.04 專案資料夾與 GitHub 公開倉庫 `githubsenna/try-everything`（<https://githubsenna.github.io/try-everything/>）**完整保留、零更動**。
   - V5.0 使用獨立資料夾 `石門國小_五年級運動會進場舞_TryEverything_V5精華版/` 與獨立 GitHub 倉庫 `githubsenna/try-everything-v5`（<https://githubsenna.github.io/try-everything-v5/>）。
3. **跨段無縫銜接視覺查核（`0:16` ➔ 原片 `1:39`）**：
   - 前奏 `0:16` 收尾姿勢為「雙掌向外攤開、轉身回正」；原片 `1:39`（主歌二②收尾接③起始）同樣處於「回正雙掌微攤收胸」準備在下一拍舉起左手斜指天之姿勢，經導師照片比對與 `ffmpeg` 合成驗證後 100% 順暢銜接。
4. **第 2 段主歌教學粒度選擇（4 格分解 vs 2 格組合）**：
   - 原本在 V4.04 該段落屬於重複複習（故合併為 2 格），但在 V5.0 已拿掉原第 2 段主歌一，此處成為學生**第一次學到「左手斜指 ➔ 右手斜指 ➔ 收胸平展雙臂 ➔ 展臂舉手收胸」**。
   - 經教學評估後決定採 **4 格獨立分解卡（`2-1`～`2-4`）**，讓五年級學生單步 `0.6x` 跟練更容易上手，全曲總計 **5 大段落 × 18 個精準分解步驟**。

## 五、完整前情提要：從 V1 到 V5.0 全歷史演進與避坑總覽（單開 V5.0 資料夾即可讀懂全貌）

1. **V1 ➔ V2（擺脫 YouTube 封鎖與干擾設計）**：
   - YouTube 嵌入播放器易遭阻擋／彈窗遮擋，且早期強制「5-6-7-8 黑幕倒數」與滴答音反而干擾課堂喊拍 ➔ 徹底改採同目錄 H.264 `.mp4` 原生 `<video>`＋系統無襯線字型（**禁止 `KaiTi` 標楷體**）＋Web Audio API 點擊／過關音效，並以無頭 Chrome 擷取真實舞者分解截圖（全文字**直接寫學生本位鏡像左右**）。
   - 建立雙版 A4 橫式滿版學習單（學生口訣小抄 ＋ 教師 100 分制 4 向度 Rubrics 評量矩陣，無浮水印、無頁碼）。
2. **V3 ➔ V4 ➔ V4.01（行動裝置置頂凍結 ＋ 無障礙操控）**：
   - 手機／直立平板 `<= 1080px` 下 `<video>` 與即時字幕自動置頂凍結；頂部 `<title>` 與標題去版本號（版本號與 **`Made by SENNA`** 統一置頁尾）；加入 **`🔍 放大影片`**、`⏮ 上一動 ／ 下一動 ⏭`、右下角 **`⬆ 回到頂端`** 與根目錄 `index.html` GitHub Pages 入口（一律經 `os.tmpdir()`＋`.nojekyll` 推送，**不在雲端硬碟目錄 `git init`**）。
3. **V4.02（逐格實看精準切點 ＋ 極簡 2 行大字）**：
   - 捨棄盲目全域重疊緩衝導致誤切進下一動過多拍子，改為資料層 `start`/`end` 連續無縫 ＋ 單步實測 `playStart`/`playEnd` ＋ 結束 **`350ms` 定格**（段尾僅留 `SEC_POST_BUFFER = 0.25s`）。
