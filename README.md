## 一、V5.0 兩分鐘精華版核心特色（5 大段落 × 28 個八拍 × 18 步・總長 `1:50`）

1. **精簡剪接不重複，2 分鐘內精彩進場**：將原片 `0:00–0:16` 前奏與 `1:39–3:13` 後半段精華（主歌＋副歌＋橋段＋結尾）透過 FFmpeg 無縫剪接合成為 **`03_影音資源/Try_Everything_V5_兩分鐘精華版原片.mp4`**，時間軸由 `0:00` 順暢播放至 `1:50`（並隨附操場廣播用 **`Try_Everything_V5_兩分鐘進場音樂.mp3`**）。
2. **第 2 段主歌細分為 4 格，學生更好練上手**：拿掉重複段落後，`0:16–0:34` 是學生第一次遇見「斜指・平展舉手」，刻意保留 **4 格教學卡片**（`2-1`～`2-4`），配合 `0.6x` 慢速與即時大字口令快速學會。
3. **手機穩定不跳段 ＋ 18 張專屬截圖 ＋ A4 雙面學習單**：完整繼承手機延遲跳轉佇列（`pendingSeekTime`）、`<= 1080px` 置頂凍結影片、一鍵放大大字模式與 100 分制四向度評量規準（Rubrics）學習單。
